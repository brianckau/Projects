# Factor exposure calculator

- Use this mode for a single stock. Reuse the ticker, listing, frequency, window, and benchmark already given. Clarify ambiguous listings. Default to both frequencies over the same trailing three-year window. For a daily-only or monthly-only request, run that frequency. Use the actual IPO-limited sample when history is short.
- Calculate CAPM market beta with an intercept using the stock's excess returns and the benchmark market's excess returns. For factor exposure, also fit an intercept plus market (MKT−RF), size (SMB, small minus big), value (HML, high minus low book-to-market), and momentum (MOM/WML, winners minus losers). Report CAPM beta separately from the market coefficient controlling for other factors.
- Default to the global model. Read [global-country-data.md](global-country-data.md) for country codes, benchmark choices, cash rates, and data provenance.
- For country exposure, select a benchmark that matches the investment question. A Hong Kong listing may have China economic exposure. State the chosen exposure geography. Use a custom benchmark CSV for unbundled markets or when the user requests another proxy. If country data are unavailable, report the global estimates and mark country beta unavailable. Regional and named-index regressions remain available on request.
- When the user asks for a named benchmark such as the Hang Seng Index, obtain that benchmark return series. For ordinary index beta, fit stock returns on index returns with an intercept, using matched periods, compatible currency and return conventions. Cite the index series and specify total return or price return. A market-only benchmark override can use a custom factor CSV with `mkt_rf` equal to benchmark return and `rf=0` to run ordinary index beta. For a custom excess-return series use `mkt_rf=benchmark return − rf` and the matching `rf`.
- Use the original Kenneth French data for published standard factors. Daily and monthly data are different source series. Do not sum daily factor returns to approximate monthly factors. Match the USD factor currency with USD stock prices or convert the adjusted price series using dated FX before calculating returns. FX conversion preserves both the stock and currency effects.

## Global and country betas

- Use a stock's USD excess return as the dependent variable. Estimate standalone global market beta and the global market, SMB, HML, and momentum coefficients. For the country model, regress the country ETF's USD excess return on the same four factors with an intercept on the final matched sample. Add its residual as the fifth predictor in the stock regression. Its slope measures domestic-market co-movement beyond all included global factors. It differs from a standalone local index beta. Both global model results use the country model's matched sample when country data are selected.
- The market factor uses VT, which covers developed and emerging equities. Size, value, and momentum use developed-market global portfolios. Disclose this universe difference. Benchmark returns represent adjusted ETF closes and are proxies for the underlying markets.
- Use USD cash for USD excess returns. The local cash columns are native-currency returns for a separate local analysis. An unhedged USD investment in local cash would also carry FX returns. Never subtract an HKD cash return directly from a USD stock return.
- Use `--global-model --country hk` for the bundled Hong Kong proxy or `--global-model --country-file file.csv` for a custom country file. The custom schema is `date,country_return_usd` in decimal total returns, using matching daily or monthly period boundaries. For global exposure alone use `--global-model`. Keep stock and country benchmark close-time differences explicit.

## Bundled data and execution

- The optional regional factor inputs are [daily](../assets/factors-daily-5y.csv) and [monthly](../assets/factors-monthly-5y.csv) USD snapshots from the [Kenneth French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html), retrieved November 18, 2026. Each file contains US, developed global, and developed Asia Pacific ex Japan rows. Use the appropriate `--region` to select one.
- The included five-year window covers October 2021 through September 2026, the latest common release at retrieval. Daily data use the provider's regional trading calendars. Monthly data use the provider's native monthly series and provide 60 observations per region. Values use decimal simple returns. `market_return` is calculated as `mkt_rf + rf`. The regression uses the supplied `mkt_rf` and subtracts `rf` from stock returns.
- Use the requested bundled model first. The global-country files are fixed snapshots. For a newer or longer global-country window, obtain matching world and country benchmark data and updated French style series. Use `--global-model --global-data updated.csv` to load that table with the same column definitions. Keep VT as the world benchmark for this path. Use `--factors` for other custom world benchmarks. When the requested period extends beyond the snapshot, attempt an archive refresh and check actual coverage before choosing the input. If the provider still ends earlier, report that date. For windows before the snapshot or additional coverage, pass a refreshed single-region factor CSV with `--factors`. Continue with explicitly disclosed overlap if the requested period is only partially covered.
- The bundled data provide the factors only. Obtain adjusted stock prices and any required FX separately.

From the skill directory with Python 3 and NumPy installed:

```bash
python3 scripts/factor_exposure.py fit --prices stock.csv --currency USD --global-model --country us --frequency daily --start 2022-01-01 --end 2024-12-31
```

For current or longer data, use `cache --region us --frequency both --refresh` and pass the selected file from `~/.cache/thesis-thinker/factors/` to `fit --factors`. To regenerate both five-year snapshots, run `python3 scripts/factor_exposure.py snapshot --output assets --refresh` and update the recorded retrieval and coverage dates.

- `--symbol` uses optional yfinance. If the provider is unavailable, use an authorized export or another verified adjusted total-return series normalized to `date,adj_close` with ISO daily dates. Pass `--prices` and cite the source. Do not silently substitute raw closes for split/dividend-adjusted prices. If only price returns are requested or available with consent, label that explicitly. Include at least the previous month-end close or previous trading-day close before the sample.
- For non-USD stocks, supply `--fx` with `date,adj_close` or `--fx-symbol`. The quote must be USD per local unit, or add `--fx-invert` for local currency units per USD. Validate FX coverage and direction. For local-currency ordinary index beta, use matching local-currency prices and custom benchmark factors, and set both `--currency` and `--factor-currency` to the local currency. Official cached factors always use USD.
- Provide `--frequency monthly` for monthly beta. When using a custom factor file, supply the matching monthly CSV. Use consecutive month-end prices and exclude partial start and end months. The seven-day month-end tolerance accommodates holidays. Check the exchange calendar for extended closures or truncated exports. Daily fitting discards mismatched intervals with missing prices or FX data. Non-synchronous market closes and sparse trading can distort beta, particularly daily.
- Use `--market-only` for the single-factor model alone. The optional custom factor format is `date,mkt_rf,smb,hml,mom,rf` in decimals. Only `date,mkt_rf,rf` are needed for market-only. Daily dates use YYYY-MM-DD. Monthly factor dates use YYYY-MM. Match any custom factor currency and conventions before fitting. Source paid datasets at runtime and keep their CSVs outside the public skill.

## Output

- Use a compact table with frequency, observations, effective dates, CAPM beta, four-factor market/size/value/momentum slopes, and model R² as relevant. Include benchmark, currency, data sources and cache date. Use Newey–West standard errors to show uncertainty when useful, especially for beta comparisons. Report a material count of factor periods dropped by alignment. Report alpha per period only if useful.
- Explain signed exposures as historical sensitivities. A positive SMB slope means the stock historically moved with the small-minus-large factor, regardless of its own capitalization. Treat fewer than 60 daily or 24 monthly observations as a fragile estimate and report insufficient data when the model cannot fit.
- Read the numerical output from the calculator. If prices, FX or factors remain unavailable, identify the specific missing input. Beta is unitless. Estimate it separately at each frequency with no annualization. Cite [Kenneth French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html) and the actual price and FX providers.
